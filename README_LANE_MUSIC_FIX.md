# STRAYLIGHT APEX — Lane & Music Fix

- Left/right steering is now a persistent 3-lane system (-4, 0, +4).
- Tapping LEFT moves one lane left and the car stays there.
- Tapping RIGHT moves one lane right and the car stays there.
- Releasing the button no longer springs the car back to the center lane.
- Keyboard arrows/A/D use the same lane-change behavior.
- Music replaced with a faster 168 BPM arcade racing track with four-on-the-floor drums, bass, arpeggio and synth stabs.
