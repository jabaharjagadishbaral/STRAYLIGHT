# STRAYLIGHT V3 — Night Racing

A redesigned Three.js arcade racer with a motorsport-style garage, procedural high-energy soundtrack, real-world-inspired car names/silhouettes, more routes, modes, live events, career rewards and leaderboard support.

## Run
```bash
npm install
npm start
```
Open `http://localhost:3000`.

## Controls
- Left / A: steer left
- Right / D: steer right
- W / Up: accelerate
- S / Down: brake
- Space: nitro
- Mobile: on-screen controls

## Note on cars
The game uses original procedural 3D silhouettes and does not ship third-party manufacturer models/logos. Vehicle names are used as catalog references; the meshes are intentionally original.
